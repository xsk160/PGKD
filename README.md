# PGKD

This is the code for the paper "A Principled Alternative to Heuristic Loss Designs in Logit-Based Graph Knowledge Distillation: Node-Level and Relation-Level Knowledge Transfer."

PGKD.py is the core loss function in this paper, which is a plug-and-play encapsulated module. You can use it in any graph knowledge distillation framework to further improve the prediction performance of student MLP.

This is the initial release. We will provide a more detailed usage guide in future updates.
